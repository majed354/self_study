# جاهزية الدراسة الذاتية

موقع ثابت يساعد فرق البرامج الأكاديمية على حصر أدلة الدراسة الذاتية وقياس جاهزية كل محك للبكالوريوس والدراسات العليا.

مصدر المحكات الحالي هو ملفات الدراسة الذاتية الرسمية في المجلد المساند:

- البكالوريوس: `TP-102 SSRP`، ويعرض `48` محكاً.
- الدراسات العليا: `TPG-102 SSRP-PG`، ويعرض `56` محكاً.

الأدلة موزعة على المحكات الرسمية بعد مواءمة ملف حصر الأدلة معها. تبويب البكالوريوس يتضمن جميع صفوف ملف `حصر الأدلة.xlsx` وعددها `503` دليل، مع حفظ مرجع الترقيم القديم لكل دليل. وتضاف في الدراسات العليا الأدلة الخاصة بالبحث العلمي والرسائل.

يعرض الموقع حكم جودة الكتابة وفق نسب الجاهزية مع بقاء منطق الوزن الأصلي: من `80%` جودة جيدة، ومن `90%` جودة جيدة جداً، وعند `100%` جودة ممتازة.

يتضمن الموقع تبويب `كتب المكتبة` المستخرج من ملف قائمة الكتب، ويعرض سجلات النسخ كاملة مع عدد نسخ كل عنوان/طبعة وتوزيعها على مكتبات الجامعة. يمكن البحث في الحقول، تصفية الكتب بحسب البرنامج والعلاقة `أساسي/مساند`، وتصدير النتائج إلى CSV أو طباعتها/حفظها كملف PDF. كما أضيفت أدلة هذا الحصر إلى المحك `5-0-1` الخاص بكفاية ومناسبة مصادر التعلم.

## التشغيل المحلي

```bash
npm run dev
```

ثم افتح:

```text
http://localhost:4173
```

## النشر على Netlify

الموقع لا يحتاج خطوة بناء. إعداد Netlify موجود في `netlify.toml`:

- Build command: يترك فارغاً
- Publish directory: `.`

ملفات البيانات التي يقرأها الموقع موجودة في `data/`.
