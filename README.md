# جاهزية الدراسة الذاتية

موقع ثابت يساعد فرق البرامج الأكاديمية على حصر أدلة الدراسة الذاتية وقياس جاهزية كل محك للبكالوريوس والدراسات العليا.

مصدر المحكات الحالي هو ملفات الدراسة الذاتية الرسمية في المجلد المساند:

- البكالوريوس: `TP-102 SSRP`، ويعرض `48` محكاً.
- الدراسات العليا: `TPG-102 SSRP-PG`، ويعرض `56` محكاً.

الأدلة موزعة على المحكات الرسمية بعد مواءمة ملف حصر الأدلة معها. تبويب البكالوريوس يتضمن جميع صفوف ملف `حصر الأدلة.xlsx` وعددها `503` دليل، مع حفظ مرجع الترقيم القديم لكل دليل. وتضاف في الدراسات العليا الأدلة الخاصة بالبحث العلمي والرسائل.

يعرض الموقع حكم جودة الكتابة وفق نسب الجاهزية مع بقاء منطق الوزن الأصلي: من `80%` جودة جيدة، ومن `90%` جودة جيدة جداً، وعند `100%` جودة ممتازة.

يتضمن الموقع تبويب `كتب المكتبة` المستخرج من ملف قائمة الكتب، ويعرض سجلات النسخ بعد تنقية الكتب والمؤلفين المستبعدين غير المتاحين حديثاً، مع عدد نسخ كل عنوان/طبعة وتوزيعها على مكتبات الجامعة. يمكن البحث في الحقول، تصفية الكتب بحسب البرنامج والعلاقة `أساسي/مساند`، وتصدير النتائج إلى CSV أو طباعتها/حفظها كملف PDF. كما أضيفت أدلة هذا الحصر إلى المحك `5-0-1` الخاص بكفاية ومناسبة مصادر التعلم.

## المرجع المنهجي (تحديث ١٤٤٨هـ)

طُوِّر الموقع ليكون مرجعاً منهجياً لا لوحة حصر فقط، بعد استيعاب ملاحظات فريق مراجعة الدراسة الذاتية (١٨٢ موضع ملاحظة / ٦٦ ملاحظة فريدة) وما بُني عليها من مهارات. أُضيفت ثلاثة تبويبات:

### 1) مسار العمل — `data/workflow.json`

سبع مراحل من جمع الأدلة إلى ربط الروابط، لكل مرحلة: السؤال الذي تجيب عنه، المدخلات، المخرجات، **بوابة الانتقال**، المهارة المسؤولة، والملاحظة المرتبطة من تقرير المراجعة.

وتحته **لوحة الطبقات الأربع** المبنية على `data/evidence-classification.json` (٥١ عنصراً في أربع طبقات):

| الطبقة | متى تُجهَّز | أثر الغياب |
|---|---|---|
| 🔴 تأسيسية | قبل أي شيء | خلل بنيوي يمنع الكتابة |
| 🟠 تشغيلية | بالتوازي مع التأسيسية | لا يمكن إثبات أن البرنامج يعمل فعلاً |
| 🟡 إثباتية | مع كل محك | لا يمكن إثبات التطبيق والقياس والتحسين |
| 🟢 مساندة | في المراجعة النهائية | لا يمنع الكتابة لكنه يقوّي الملف |

لكل عنصر بنود فحص ومستوى حرجية وحالة (متوفر / جزئي / ناقص) تُحفظ في المتصفح، وتُحسب منها جاهزية كل طبقة و**قرار البدء**: الطبقتان التأسيسية والتشغيلية ≥ ٨٠٪ بلا عنصر حرج ناقص ⇒ ابدأ الكتابة.

### 2) الأدلة المؤسسية — `data/institutional-evidence.json`

سجل ٣٨ وثيقة مرجعية مشتركة بين برامج الكلية على ثلاثة مستويات: نماذج المركز الوطني، ولوائح جامعة الطائف وأدلتها، ووثائق الكلية والقسم. لكل وثيقة: الجهة المصدرة، وتصنيفها، وحالتها (معتمد / للتأكيد)، وتنبيه الإصدار والنسخة، وصيغة الاستخدام في المتن، و**المحكات التي تخدمها في البرنامجين** — مستخرجة بمطابقة نصية مع ملف الحصر وتُعامَل كاقتراح يُراجَع.

ويظهر هذا الربط معكوساً داخل تبويب المحكات: عند فتح أي محك يعرض الموقع «الإطار المؤسسي المقترح لافتتاح هذا المحك».

قاعدة السجل: قبل الإحالة إلى أي وثيقة، ابحث عن كل نسخها في مجلد الأدلة كله، واعتمد الأحدث، ووحّدها في جميع المحكات، واذكر سنتها في المتن قبل `&`.

### 3) دليل الكتابة — `data/writing-guide.json`

خمسة أقسام:

- **القاعدة المعتمدة**: بنية نص المحك بعد ملاحظة (ع-03) — سرد تحليلي متصل، فقرة لكل عبارة مفتاحية بترتيبها، بلا عناوين «قوة/ضعف/تحسين» داخل المحك، مع المنطق الرباعي (النهج → التطبيق → التعلم → التكامل)، وقواعد الإحالة وصيغة `&`.
- **الصياغة المثالية**: قوالب جاهزة لكل موضع (افتتاح الإطار المؤسسي، فقرة العبارة المفتاحية، التأطير والمتابعة، ذكر القصور، أولويات التحسين) وعبارات محظورة وبدائلها.
- **نموذج محك مكتمل**: المحك ١-١-٥ مكتوباً بالبنية المعتمدة بخمس فقرات، مع نموذج ما يُكتب في نهاية المعيار.
- **قائمة التحقق**: ١١ بنداً قبل تسليم أي محك، بحالة محفوظة في المتصفح.
- **أخطاء المراجعة**: الأخطاء الاثنا عشر المتكررة، وكيف يُكتشف كل منها، وأثره — والعناصر الخمسة الواجبة في أي تقرير تحليلي يُرفع كدليل.

### توليد سجل الأدلة المؤسسية

```bash
python3 tools/build-institutional.py
```

يعيد بناء `data/institutional-evidence.json` من سجل الوثائق داخل السكربت، ويربط كل وثيقة بمحكات البرنامجين بمطابقة نصية مع ملفات الحصر.

## التشغيل المحلي

```bash
npm run dev
```

ثم افتح:

```text
http://localhost:4173
```

## النشر على Netlify

الموقع لا يحتاج خطوة بناء. إعداد Netlify موجود في `netlify.toml`:

- Build command: يترك فارغاً
- Publish directory: `.`

ملفات البيانات التي يقرأها الموقع موجودة في `data/`.
