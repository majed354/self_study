# جاهزية الدراسة الذاتية

موقع ثابت يساعد فرق البرامج الأكاديمية على حصر أدلة الدراسة الذاتية وقياس جاهزية كل محك للبكالوريوس والدراسات العليا.

## التشغيل المحلي

```bash
npm run dev
```

ثم افتح:

```text
http://localhost:4173
```

## النشر على Netlify

الموقع لا يحتاج خطوة بناء. إعداد Netlify موجود في `netlify.toml`:

- Build command: يترك فارغاً
- Publish directory: `.`

ملفات البيانات التي يقرأها الموقع موجودة في `data/`.
